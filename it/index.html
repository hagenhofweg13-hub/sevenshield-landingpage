Crittografato all'invio, non solo in archivio

Una cartella bloccata può essere condivisa normalmente via email, chiavetta USB o cloud storage. Il destinatario ha bisogno solo di SevenShield e della password corretta per aprirla. In questo modo SevenShield protegge i documenti sensibili anche durante la trasmissione, non solo sul disco rigido.

Importante per l'invio

Comunica la password tramite un canale diverso da quello del file stesso, ad esempio per telefono invece che nella stessa email. Altrimenti la crittografia perde il suo scopo.

Leggi sul telefono

Il destinatario non deve installare nulla. Apri il file nel browser, inserisci la password, fatto: sevenshield.de/oeffnen. Tutto avviene sul dispositivo, nulla viene caricato. La pagina è disponibile anche come file offline con checksum.

Crittografa il testo delle email e gli allegati

Tieni le informazioni riservate fuori dal corpo dell'email. Con SevenShield scrivi il messaggio in una finestra apposita, aggiungi file se serve e invii tutto come un unico file crittografato. Il destinatario lo apre gratis.

01

Scrivi il messaggio

Inserisci il testo, con correzione ortografica. Viene crittografato direttamente in memoria e mai salvato in chiaro.

02

Trascina gli allegati

Aggiungi file con il trascinamento, fino a 20 allegati e 25 MB. Tutto confluisce in un unico file crittografato.

03

Invia la password a parte

SevenShield crea una password propria per questo invio e apre l'email con il file. La tua password principale resta segreta.

04

Il destinatario apre gratis

Con SevenShield e la password il testo compare in una finestra e gli allegati si possono salvare uno alla volta. Decrittografare è gratuito.

Utile sapere

Oggetto, mittente e destinatario dell'email restano leggibili. Inserisci le informazioni riservate solo nel messaggio crittografato e invia la password per un'altra via.
