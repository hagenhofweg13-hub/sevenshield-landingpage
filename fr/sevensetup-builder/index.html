Transformer votre dossier de programme en Setup.exe : SevenSetup Builder

Quiconque distribue un logiciel a besoin d’un setup qui installe, met à jour et supprime proprement. Le SevenSetup Builder le crée à partir de votre dossier de programme terminé, sans script et sans recompiler. Le setup fonctionne aussi sur des ordinateurs sans .NET installé.

  • Une seule Setup.exe à partir de votre dossier de programme, en quelques étapes et sans langage de script
  • Informations préremplies : nom, version et éditeur sont repris de votre exe et peuvent être modifiés
  • Votre propre apparence : logo, texte de licence et couleur d’accentuation, pour que le setup s’accorde à votre programme
  • Installation pour l’utilisateur connecté ou pour tous les utilisateurs, au choix avec raccourci sur le bureau et démarrage automatique
  • Mises à jour et désinstallation : le même nom avec une version supérieure met à jour, la désinstallation se fait via « Applications installées »
  • Installation silencieuse en ligne de commande pour le déploiement en entreprise
Télécharger SevenSetup Builder Conditions d’utilisation

Le Builder nécessite le runtime .NET 8 Desktop sur votre ordinateur, les setups créés n’en ont pas besoin. Au premier démarrage, Windows peut afficher un avertissement de sécurité car les fichiers ne sont pas signés. Démarrez-les via « Informations complémentaires » puis « Exécuter quand même ».

Guide rapide SevenSetup

  1. DémarrerOuvrir SevenSetupBuilder.exe.
  2. Choisir le dossierChoisir le dossier de programme terminé, par exemple le dossier publish, et le programme principal dans la liste.
  3. Vérifier les informationsContrôler le nom, la version et l’éditeur. Au choix, sélectionner un logo, un texte de licence et une couleur d’accentuation.
  4. CréerDéfinir ce que le setup doit proposer, puis cliquer sur « Créer seulement » ou « Créer et installer ».

Mises à jour : L’identifiant interne est formé à partir du nom. Pour une mise à jour, créez le nouveau setup avec le même nom et une version supérieure. Le setup conserve le dossier et le type d’installation, ferme le programme en cours après confirmation et supprime les fichiers de la version précédente qui n’existent plus. Il avertit si une version plus récente est déjà installée.

Logo et couleur dans le programme : Avec l’option « Utiliser le logo aussi pour les raccourcis et le programme », le setup place le logo et l’icône à côté de l’exe. Les raccourcis et l’entrée dans « Applications installées » utilisent cette icône. Votre programme peut en reprendre le logo et la couleur d’accentuation s’il le prend en charge.

Ligne de commande : Setup.exe /silent [/allusers] [/dir=C:\Chemin] [/autostart] [/nodesktop] [/force]. La valeur de retour est 0 en cas de succès.

Essai et licence : 14 jours à partir du premier démarrage avec toutes les fonctions. Ensuite, le démarrage, le chargement et l’enregistrement des informations restent possibles, seul « Créer le setup » est bloqué jusqu’à l’installation d’un fichier de licence (.lic). Les setups déjà créés ne sont pas concernés. « Commander une licence » dans le programme ouvre un e-mail avec l’identifiant de votre ordinateur.

Questions fréquentes sur le SevenSetup Builder

Ce que fait le programme, ce qu’il coûte et comment fonctionne la licence.

Qu’est-ce que le SevenSetup Builder ?

Un programme Windows qui transforme un dossier de programme terminé en une seule Setup.exe. Le setup installe pour l’utilisateur connecté ou pour tous, crée des raccourcis, prend en charge les mises à jour et peut être supprimé via « Applications installées ».

Mes clients ont-ils besoin de .NET ?

Non. La Setup.exe créée est autonome et fonctionne sans .NET installé. Le Builder lui-même nécessite le runtime .NET 8 Desktop sur votre ordinateur.

Dois-je écrire des scripts ou recompiler mon programme ?

Non. Vous choisissez votre dossier de programme terminé et remplissez un court formulaire. Votre programme n’est pas modifié, le Builder place simplement vos fichiers dans le setup.

Comment fonctionnent les mises à jour ?

Créez le nouveau setup avec le même nom et une version supérieure. À l’exécution, il détecte l’installation existante, conserve le dossier et le type d’installation, ferme le programme en cours après confirmation et remplace les fichiers. Les fichiers de la version précédente qui n’existent plus sont supprimés.

Combien coûte le SevenSetup Builder et combien de temps puis-je l’essayer ?

Vous pouvez l’essayer 14 jours à partir du premier démarrage avec toutes les fonctions. Ensuite, il coûte 99 € une seule fois (en tant que petite entreprise selon le § 19 UStG, sans TVA facturée) et est valable pour un ordinateur.

Comment obtenir une licence ?

Cliquez sur « Commander une licence » dans le programme ou écrivez à support@sevenshield.de en indiquant l’identifiant de votre ordinateur. Vous recevez la facture et un fichier de licence (.lic) par e-mail et chargez le fichier dans le programme. Une licence SevenShield ou SevenErase ne s’applique pas au Builder.

Que se passe-t-il à la fin de l’essai ?

Le démarrage, le chargement et l’enregistrement des informations restent possibles. Seul « Créer le setup » est bloqué jusqu’à l’installation d’un fichier de licence. Les setups déjà créés ne sont pas concernés.

Puis-je exécuter le setup sans interface ?

Oui, avec Setup.exe /silent. Il existe aussi les options /allusers, /dir=, /autostart, /nodesktop et /force. La valeur de retour est 0 en cas de succès.

Y a-t-il des limites ?

Seul le 64 bits (win-x64) est pris en charge, le setup a un design sombre et la Setup.exe créée n’est pas signée, c’est pourquoi Windows peut afficher un avertissement au premier démarrage.
